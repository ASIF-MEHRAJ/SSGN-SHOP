# 🛍️ SSGN SHOP

SSGN SHOP is a modern e-commerce web application built with **React** and **Redux Toolkit**. It offers a seamless online shopping experience through a clean, responsive, and intuitive interface.

The application allows users to explore products, search for specific items, view detailed product information, manage their shopping cart, maintain a wishlist, and proceed through the checkout process. State management is handled efficiently using Redux Toolkit, ensuring smooth performance and a consistent user experience across the application.

The project is designed with reusable components, organized folder structure, and responsive layouts, making it scalable, maintainable, and easy to extend with additional features in the future.

## ✨ Features

- 🏠 Modern and responsive user interface
- 🔍 Product search functionality
- 📦 Product listing and detailed product pages
- ❤️ Wishlist management
- 🛒 Shopping cart with quantity management
- 💳 Checkout page
- ⚡ Fast and efficient state management using Redux Toolkit
- 📱 Fully responsive design for desktop, tablet, and mobile devices

## 🛠️ Tech Stack

- React
- Redux Toolkit
- React Router
- Vite
- CSS
